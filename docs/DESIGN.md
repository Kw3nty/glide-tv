# Glide TV — дизайн-система

Интерфейс для пульта и экрана в 3 метрах. Код — `app/src/main/java/app/glidetv/ui/widgets/Ui.kt`.

## Принципы

- **Фокус виден всегда.** Кнопка в фокусе — белая заливка с тёмным текстом и увеличение 1.04 (150 мс). Строки списка и карточки — белая рамка 3dp.
- **Цвет не единственный сигнал.** Статус = цвет + иконка + текст (`StatusView`, `Tone`). Выбранный пункт меню — подложка + циан. Выбранный язык — галочка. Выключенная кнопка — только контур.
- **Без эмодзи.** Только векторные иконки `res/drawable/ic_*.xml` (24×24, линия 2, скруглённые концы), тонируются в коде.
- **Результат на экране.** Итог операции показывается в `StatusView` или карточке, а не только во всплывающем окне. Длинная операция: кнопка выключена, есть индикатор и счётчик «N из M».
- **Безопасная зона.** Отступы экрана 48×27dp (≈5 % overscan). Контентная область ≈ 624×486dp на ТВ 1080p — проверяйте, что ряд кнопок помещается.

## Токены (`Palette`)

| Токен | Цвет | Назначение |
|---|---|---|
| `BG` / `BG_DEEP` | `#0A1630` / `#071027` | фон / поля ввода |
| `CARD` / `CARD_FOCUS` | `#12244A` / `#1B3366` | карточки / вторичные кнопки, выбранное |
| `OUTLINE` | `#4A6699` | смысловые границы (≥ 3:1 к фону) |
| `ACCENT` / `ON_ACCENT` | `#3EE6FF` / `#04132B` | главное действие |
| `TEXT` / `TEXT_DIM` | `#F5F8FF` / `#AFC1E3` | основной (≥ 11:1) / вторичный (≥ 6.8:1) текст |
| `FOCUS` / `ON_FOCUS` | `#FFFFFF` / `#0A1630` | фокус (17.9:1) |
| `OK` / `WARN` / `ERR` | `#4ADE80` / `#FBBF24` / `#FB7185` | статусы (≥ 4.6:1 на любой поверхности) |

## Типографика (`Type`, sp)

`TITLE` 28 · `SECTION` 21 · `BODY` 18 · `SECONDARY` 16 · `CAPTION` 14 (минимум). Отступы кратны 4/8dp: 8 / 16 / 24 / 32.

## Компоненты

- `actionButton(label, primary, iconRes)` — высота ≥ 56dp; `primary` — одно главное действие на экране.
- `card(focusable)` — радиус 20dp, отступ 20–24dp.
- `chip(label, color)` — метка статуса или размера.
- `StatusView` — `progress` / `info` / `success` / `warn` / `error`, озвучивается экранным диктором.
- `tvListView` + `CheckRow` — список с галочками, OK переключает.
- `RingGauge` — процент + подпись внутри кольца.
